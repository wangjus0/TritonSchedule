### Quick Start

Clone the project

```bash
  git clone https://github.com/wangjus0/TritonSchedule.git
```

Go to the project directory

```bash
  cd TritonSchedule
```

Install dependencies

```bash
  npm install
```

Start the application

```bash
  npm run dev
```
